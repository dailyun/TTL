# TodoTodoList 低保真线框 v0.1

这些线框用于讨论信息架构和页面优先级，不代表最终视觉设计。

## 1. App Shell

```txt
┌────────────────────────────────────────────────────────────────────┐
│ TodoTodoList              [快速记录一个想法或事项...]   [搜索] [+] │
├───────────────┬────────────────────────────────────────────────────┤
│ 首页          │                                                    │
│ 收集箱        │ 当前视图标题                         [筛选] [同步] │
│ 全部          │                                                    │
│ 看板          │ 页面内容                                           │
│ 日历          │                                                    │
│ 版块          │                                                    │
│ 设置          │                                                    │
└───────────────┴────────────────────────────────────────────────────┘
```

设计意图：

- 左侧导航稳定，减少页面间切换成本。
- 顶部始终保留快速新增，保证记录入口足够近。
- 同步状态先作为占位，后续接入 Google Calendar 和 GitHub。

## 2. 首页：收集箱 + 今日 + 正在

```txt
┌────────────────────────────────────────────────────────────────────┐
│ 首页                                                2026-07-07 周二 │
├──────────────────────┬──────────────────────┬──────────────────────┤
│ 收集箱               │ 正在                 │ 今日                 │
│ 3                    │ 5                    │ 4                    │
├──────────────────────┼──────────────────────┼──────────────────────┤
│ □ 研究 GitHub 同步   │ ▶ 写产品方案         │ 09:30 产品会议       │
│   Idea · 工作        │   Todo · 工作        │     Google Calendar  │
│                      │                      │                      │
│ □ 周末想去徒步       │ ▶ 整理生活开销       │ 14:00 健身           │
│   Idea · 生活        │   Todo · 生活        │     Event · 生活     │
│                      │                      │                      │
│ □ 试试新的读书流程   │ ▶ 搭建本地原型       │ 18:30 晚餐           │
│   Idea · 个人        │   Todo · 工作        │     Event · 生活     │
└──────────────────────┴──────────────────────┴──────────────────────┘
```

适合的用户行为：

- 早上打开应用，先看今天和正在。
- 快速清理收集箱。
- 把想法拖到正在或安排时间。

可替代方案：

- 如果你更偏执行，可以让首页默认是看板。
- 如果你更偏日程，可以让首页默认是周日历。

## 3. 快速新增

```txt
┌────────────────────────────────────────────────────────────────────┐
│ 记录                                                               │
├────────────────────────────────────────────────────────────────────┤
│ 标题  [                                                         ]  │
│                                                                    │
│ 类型  [Idea ▼]   状态 [想要 ▼]   版块 [收集箱 ▼]                  │
│ 时间  [无时间 ▼]  标签 [添加标签]                                 │
│                                                                    │
│ 描述                                                               │
│ [                                                                ] │
│ [                                                                ] │
│                                                                    │
│                                      [取消] [保存]                 │
└────────────────────────────────────────────────────────────────────┘
```

默认规则：

- 标题是唯一必填项。
- 默认类型为 Idea。
- 默认状态为想要。
- 默认版块为收集箱。
- 选择时间后可以提示是否切换为 Event。

## 5. 状态看板

```txt
┌────────────────────────────────────────────────────────────────────┐
│ 看板                                      [版块: 全部] [显示完成]  │
├────────────┬────────────┬────────────┬────────────┬──────────────┤
│ 想要 12    │ 正在 5     │ 搁置 4     │ 放弃 2     │ 完成 18      │
├────────────┼────────────┼────────────┼────────────┼──────────────┤
│ 研究同步   │ 写方案     │ 学习法语   │ 旧博客迁移 │ 完成周报     │
│ Idea·工作  │ Todo·工作  │ Idea·生活  │ Todo·工作  │ Todo·工作    │
│            │            │            │            │              │
│ 徒步计划   │ 搭原型     │            │            │ 读完书       │
```

设计意图：

- 状态看板是清理和推进的主工具。

- 拖拽改变状态，点击打开详情。

## 8. 设置：同步与数据

```txt
┌────────────────────────────────────────────────────────────────────┐
│ 设置                                                               │
├────────────────────────────────────────────────────────────────────┤

│ owner [        ] repo [        ] branch [main] path [todotodolist] │
│ [测试连接] [拉取 GitHub] [推送到 GitHub]                            │
│                                                                    │

```

第一版建议：

- JSON 导入导出进入 MVP。
- Google 和 GitHub 从第一阶段就按同步能力设计，但界面要清楚显示连接、同步中、冲突和失败状态。
- 真正启用同步前，需要先确定 token 和 OAuth 方案。

## 9. 移动端方向

移动端建议采用底部导航：

```txt
┌────────────────────┐
│ [快速记录...]      │
├────────────────────┤
│ 首页内容           │
│                    │
│                    │
├────────────────────┤
│ 首页 全部 看板 日历 │
└────────────────────┘
```

优先级：

- MVP 可以先保证响应式可用。
- 原生移动端 App 不进入第一阶段。

## 10. 需要确认的界面问题

1. 首页已确定为「收集箱 + 今日 + 正在」三块组合。
2. 看板是否默认隐藏「放弃」和「完成」。
3. 日历是否以周视图作为第一版主视图。
4. 详情编辑是否使用右侧抽屉。
5. 设置页的同步状态、冲突提示和失败重试如何呈现。
